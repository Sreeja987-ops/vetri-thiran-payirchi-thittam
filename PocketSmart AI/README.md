# 🛍️ PocketSmart AI - Smart Budget Assistant

PocketSmart AI is an AI-powered budget planner that helps users plan their home interior, parties, and jewelry purchases within their budget using Google Gemini AI.

### ✨ Features
- 🔐 User Authentication - Secure Register / Login
- 🏠 Home Interior Planner - Budget-wise recommendations
- 🎉 Party Planner - Plans for birthdays, weddings
- 💍 Jewelry Planner - Suggestions based on occasion
- 📜 History Tracking - Saves all your past plans
- 🤖 Gemini AI Powered

### 🛠️ Tech Stack
- Backend: FastAPI (Python)
- AI: Google Gemini API
- Auth: JWT + Passlib
- Frontend: HTML + Jinja2

### 🚀 How to Run
1. pip install -r requirements.txt
2. Add GEMINI_API_KEY in .env file
3. python main.py
4. Open http://127.0.0.1:8000
